Zone utilization

One row per zone, one cell per gas day. Color is flow as a percentage of that day's outage-adjusted capability (or nameplate base capability, when no outage is active). Cells running past dark rust into navy mean flow exceeded the zone's stated capability that day. Hover a cell for detail.

Facility constraint log

Every facility named in a daily outage description, extracted from the free text and ranked by total impact volume. When more than one facility is named on the same zone-day, each is credited with that day's full zone impact — see docs/schema.md for the exact rule.

Monthly utilization vs. AER reference price

System-wide monthly average utilization against the Alberta natural gas reference price for the same month (the only price series in this project — see the README for why no daily AECO price is included).

Notable constraint events

Named-facility outages paired with what happened to utilization on their zone while active. Deviation from seasonal normal only appears once at least one prior year of same-month history exists — this list gets more useful as the pipeline runs longer.

Data sources

  • NGTL/Foothills base capabilities, daily flow & outage history, plant turnaround activity, and raw outage register — TC Energy public CSV endpoints
  • Alberta natural gas reference price (monthly, $/GJ, 1994–present) — alberta.ca, the official input to Crown royalty valuation

No Bloomberg, Refinitiv, ICE, NGI, Nasdaq Data Link, or any other paid terminal or proprietary feed was used anywhere in this project — every number above comes from a free, public source. Daily AECO spot prices are not freely available and are not estimated or fabricated here; the AER monthly reference price is the only price series shown.
